# Cognifyz Data Analysis Internship – Level 3

## Project Overview
This project contains Python-based data analysis tasks completed as part of the Cognifyz Data Analysis Internship using the Zomato restaurant dataset.

## Tasks Completed

### Task 1: Restaurant Reviews
- Analysed restaurant rating categories.
- Calculated average aggregate ratings by category.
- Created a rating distribution chart.

**Limitation:** The supplied dataset does not contain written customer reviews. Therefore, keyword sentiment and review-length analysis could not be performed.

### Task 2: Votes Analysis
- Identified restaurants with the highest and lowest votes.
- Calculated total, average and median votes.
- Analysed correlation between votes and aggregate ratings.
- Identified the top 10 most-voted restaurants.
- Created visualisations.

### Task 3: Price Range vs Online Delivery and Table Booking
- Analysed restaurant counts by price range.
- Calculated online delivery availability percentages.
- Calculated table booking availability percentages.
- Compared service availability across price ranges.
- Created comparison charts.

## How to Run

1. Install the required libraries:

   ```bash
   pip install pandas matplotlib numpy
   ```

2. Keep the dataset in the same folder as `main.py`.
3. Run:

   ```bash
   python main.py
   ```

## Conclusion
The project explores restaurant ratings, voting patterns, and service availability using Python data analysis techniques. It demonstrates practical data cleaning, grouping, statistical analysis, visualisation, and result exporting.
