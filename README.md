# 📊 Cognifyz Data Analysis Internship

Welcome to my **Cognifyz Data Analysis Internship Projects** repository!

This repository contains the data analysis tasks I completed during my internship using Python and the Zomato restaurant dataset.

## 👨‍💻 About the Project

The objective of this internship was to explore restaurant-related data, identify meaningful patterns, perform statistical analysis, and create visualisations to communicate findings.

## 📌 Project Levels

### Level 1 – Basic Analysis
- Top cuisines and their distribution.
- Restaurant distribution and ratings by city.
- Price range distribution.
- Online delivery analysis.

### Level 2 – Intermediate Analysis
- Restaurant rating distribution.
- Cuisine combination analysis.
- Geographic analysis using restaurant locations.
- Restaurant chain analysis.

### Level 3 – Advanced Analysis
- Restaurant rating category analysis.
- Votes and aggregate rating correlation.
- Price range comparison with online delivery and table booking.

**Dataset limitation:** The supplied dataset does not contain written customer review text. Therefore, Task 1's keyword sentiment and review-length analysis could not be performed.
